Algorithm Blueprint: Deterministic Z-Score Rescaling

The ChameleonOS Normalization Engine calibrates raw scores into standardized z-distributions to eliminate grader harshness, leniency, and variance discrepancies.

1. Standardization Formula

z_{j, p} = (R_{j, p} - μ_j) / σ_j

Measures how many standard deviations project \(p\) is above or below judge \(j\)'s historical mean.

2. Zero-Variance Safeguard

if σ_j ≤ 10^{-6}: z_{j, p} = 0.0

When a judge scores every project identically, division by zero is prevented; their votes contribute neutrally at \(z = 0\).

3. Benchmark Rescaling

S_{norm} = μ_{global} + (z_{avg} × σ_{global})

Standardized scores are mapped back to the event's global scale for intuitive interpretation.

4. Deterministic Tie-Breaker

  • Normalized Score (descending)
  • Raw Aggregate Score (descending)
  • Total Evaluation Count (descending)
  • Project Identifier (lexicographical ascending)
